# Telegram Bot

Этот репозиторий содержит исходный код Telegram-бота [@double_zaza_bot](https://t.me/double_zaza_bot).

## 📌 О боте
Бот предназначен для регистрации пользователей и хранения их контактных данных. Позволяет пользователям вводить и сохранять номер телефона, а также просматривать информацию о себе.

## 🚀 Функционал
- Регистрация пользователя с командой `/start`
- Добавление номера телефона с помощью `/set_phone <номер>`
- Просмотр информации о себе через `/me`
- Просмотр информации о себе через эндпоинт `/me`
